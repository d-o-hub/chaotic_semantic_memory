# Skill Catalog

33 skills. Load with `skill` tool when task matches trigger.

Generated by `scripts/gen-skill-catalog.sh` from the tree: the count, the
sections and every row come from the YAML front matter of the matching
`.agents/skills/*/SKILL.md`, never from hand-typed table rows. Re-run the
script after adding, removing or renaming a skill. SKILL.md conformance is
gated by `scripts/validate-skill-format.sh`; catalog drift by
`scripts/check-skill-catalog.sh`.
