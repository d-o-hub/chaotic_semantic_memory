# GOAP Orchestrator

Use this skill whenever a task needs coordinated multi-agent execution, implementation gap analysis, and structured architecture decision records.

## Goal
Deliver end-to-end implementation by:
1. Planning with GOAP (Goal-Oriented Action Planning) before coding.
2. Delegating each missing task to specialist agents.
3. Capturing non-trivial decisions in ADR format.
4. Re-integrating and verifying all outputs.

## Trigger Scenarios
- User asks for orchestrator behavior.
- Task includes broad implementation with multiple missing parts.
- Work requires architecture decisions and execution sequencing.
- Work spans planning, coding, testing, docs, and release artifacts.

## Required Workflow

### 1) State Discovery
- Build a current-state snapshot: existing modules, tests, failing areas, missing deliverables.
- Build desired end-state acceptance criteria.
- Compute gaps as explicit missing tasks.
- Load `references/goap-actions.md` for action schema.

### 2) GOAP Plan Construction
- Create a GOAP problem:
  - Goal: all acceptance criteria satisfied.
  - Initial state: discovered repository state.
  - Actions: from `references/goap-actions.md`.
- Output ordered action list with preconditions/effects for each action.
- Persist plan artifact under `plans/`.
- Prefer `scripts/build_goap_plan.py <goal> <output_path>` to generate a deterministic action list.

### 3) Specialist Agent Spawn
- Prefer `scripts/orchestrate.py` to materialize specialist assignment boards from GOAP plan + missing tasks.
For each missing task category, assign exactly one specialist lane:
- `architecture-agent`
- `implementation-agent`
- `test-agent`
- `performance-agent`
- `persistence-agent`
- `wasm-agent`
- `release-agent`

Use handoff contract from `references/specialist-handoff.md`.
Each specialist must return:
- files changed
- validation executed
- unresolved risks

### 4) ADR Decision Capture
- For all architectural tradeoffs, create or update ADR docs using `references/adr-template.md`.
- Prefer `scripts/create_adr.py --slug <slug> --title <title>` for deterministic ADR file creation.
- ADR entries are mandatory when decisions affect persistence, runtime model, API shape, scaling, or reliability.

### 5) Merge and Verify
- Merge specialist outputs in dependency order.
- Run full verification loop from the local rust-verification skill.
- Ensure no mock placeholders, no TODOs, and no unresolved blockers.

### 6) Completion Gate
Only complete when all are true:
- GOAP goal state is satisfied.
- Specialist outputs integrated.
- ADRs updated.
- Verification commands succeed.
- Runnable example demonstrates behavior.

## Output Contract
- A concise orchestration summary.
- Orchestration board artifacts (`.json` + `.md`) generated by script.
- GOAP plan artifact path.
- Specialist task table with status.
- ADR file list updated.
- Verification checklist with command outcomes.
