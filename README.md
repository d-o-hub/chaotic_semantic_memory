# chaotic_semantic_memory

AI memory system using hyperdimensional computing and echo state networks.

## Features

- Hyperdimensional vector representations (10240-bit)
- Echo state network reservoir computing
- libSQL-based persistence
- WASM support

## Usage

```rust
use chaotic_semantic_memory::prelude::*;

fn main() -> Result<()> {
    // See examples/
    Ok(())
}
```
