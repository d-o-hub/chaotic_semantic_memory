feat: implement A Cyclic discrete neural circuit map from Long, 2026

What
Introduces the Cyclic Discrete Neural Circuit Map (CDNCM) as a new chaotic projection primitive in crates/csm-chaos and crates/csm-core-lib under the experimental-neural-circuit feature flag. Also addresses unrelated compilation warnings across the library regarding format strings and float bounds checking.

Research basis
Long, Tang, Xiong, Bian (2026-07-23). "A Cyclic discrete neural circuit map with hyperchaotic dynamics and an application to adaptive DNA image encryption". https://doi.org/10.1140/epjp/s13360-026-08088-4

Design
The map iteratively computes states over 3 interrelated variables using a nonlinear tanh interaction function which provides distinct chaotic projection characteristics. The structural update computes next() to advance the system and next_value() to condense the 3x64-bit state registers into a final uniformly distributed pseudo-random output.

Tradeoffs
The 3D state update using tanh is naturally more computationally expensive than simpler maps like Slhm2d (which completes 10k items in roughly half the time), but provides higher dimension embedding potential for complex cryptographic or high-fidelity hashing.
