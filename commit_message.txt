🧪 Add tests for WASM encode_text

🎯 **What:** Testing gap addressed for `encode_text` function in `src/wasm.rs`. Since the function is exported via `#[wasm_bindgen]`, but standard Rust tests inside the project check behavior without building a WASM payload, we added native unit tests in `src/wasm_ext.rs` to explicitly verify its logic.

📊 **Coverage:** Added test cases covering:
  * Deterministic encoding of strings (`wasm_encode_text_consistency`).
  * Expected 1280-byte length constraint (`wasm_encode_text_length`).
  * Proper handling of an empty string (`wasm_encode_text_empty`).
  * Proper difference behavior across non-identical strings (`wasm_encode_text_difference`).

✨ **Result:** Improved test coverage, guaranteeing correctness and resilience of HDC text encoding from WASM interfaces.
