## What this round adds to the method

1. **An empty branch is a resubmission that passes every title-level check.** #860's title, body and
   `MERGEABLE` state all read normally; only `gh pr diff`/`changed_files`/a local three-dot diff
   reveal that the PR merges nothing. Check content before reading roasts.
2. **A green CI can be green about another package.** This repo's root manifest is a package *and*
   a workspace with no `default-members`, so `cargo metadata`'s `workspace_default_members` is just
   the root package; feature-gated member-crate modules get no coverage unless the feature is
   forwarded (only `experimental-neural-circuit` is) or pinned per crate. Verify with
   `cargo test -p <crate> --features <feature>` locally before trusting the green.
3. **The reconciliation gate caught a live drift on an unrelated tree.** #842 closed at 08:09:35Z
   with `consolidate_the_three_hook_installers` still queued (`status: in_progress`); the gate fails
   closed on it and this PR removes the entry (7 → 6). Same mechanism as its 2026-10-05 first catch.
