## #800 — detailed roast

**CI truth (`e5333ca5`).** Every job green except `commitlint`; its annotation:

> `perf PR evidence gate: missing `## Performance Evidence` section in the PR body`

Not a flake, not infrastructure (Cargo Deny, `lint`, `test`, `mutation-test`,
`miri`, the workspace crates and the benchmark jobs all passed).

**Correctness — sound, and already locked.** For `shift ≡ 0 (mod 10240)` the old
code took `bit_shift == 0` with `word_shift == 0`: `split_at(0)`, then two
`copy_from_slice` calls that reproduce the input in `result`. `return *self` is
byte-identical, and `crates/csm-core-lib/src/hyperdim_tests.rs:48`
(`assert_eq!(v, v.permute(0))`) already asserts it. The neighbouring
`bit_shift == 0 && word_shift != 0` branch is untouched and stays covered by
`permute(128)` at line 49 — no new correctness test is required.

**Reachability — why this is not a no-op close.** `crates/csm-core-lib/src/encoder.rs:226`
permutes `pos.saturating_mul(position_stride)` with `pos` from `.enumerate()`,
so position 0 calls `permute(0)`: the branch fires once per `encode`.

**Evidence bar (what a resubmission must carry).**

1. A `## Performance Evidence` section **in the PR body** — the gate reads the
   body, never the commits — naming a baseline from
   `plans/evidence/bench/canonical.json` or "the nearest canonical comparator
   plus the new benchmark output", plus a path/URL-shaped Criterion artifact and
   a numeric before/after pair. The nearest canonical comparator here is
   `text_encoder/encode_short` (the caller path that reaches position 0);
   `hamming_distance` exists as a lower-level neighbour, but no canonical id
   covers `permute` itself.
2. A benchmark that reaches the new branch. The only existing `permute` bench is
   `benches/binary_benchmark.rs:30` → `permute(321)`; `321 % 128 = 65`, so it
   never enters the `bit_shift == 0` path. Parameterize with `0` and `10240`, or
   bench `Encoder::encode`.
3. Dead-code-elimination care: a bench that calls `permute(0)` and drops the
   returned 1,280-byte vector lets LLVM elide the copy — the "~0 ns" shape.
   `black_box` the result and run both variants under identical instrumentation.
4. The share of the win: one identity permutation out of `N` tokens per encode.
   If the whole-`encode` delta is inside the run-to-run spread, the honest
   outcomes are a caller-side skip (`if pos != 0`, no branch in the hot function)
   or a no-impact close with that measurement attached.
