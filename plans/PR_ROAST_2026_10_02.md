## #809 — roast notes

**Failure signature read from the logs, not the badge.** Job 110457219603's `Verify WASM TS Freshness` step printed a three-line diff — all of it closure helpers — then `STALE` and exit 1; job 110447942669 (run 36885556956, different commit) showed the identical diff. Every other job in both runs passed or was cancelled as a consequence of the failed run.

**The filter was narrowed, the snapshot left alone.** Refreshing `wasm/chaotic_semantic_memory.d.ts` would have baked in today's generated hashes and preserved the same failure mode for the next toolchain bump. The new expression is anchored at the declaration start and still compares `InitOutput` members, `__wbindgen_*` ABI signatures and public exports; four mutation fixtures confirm the gate still fails on real drift.

**Root-`src` coverage is the second half of the fix.** Without it, the same class of breakage — a root `src/**` change that alters the generated bindings — keeps reaching `main` untested, because PR runs skipped the job entirely. The PR's own diff now triggers the job, which is also how the fix was validated on the real toolchain: `Verify WASM TS Freshness` → `OK` on head `d0536879`.

**Limitation recorded honestly in the body.** The workstation's wasm-pack (0.15.0) emits the *old* helper names, so the local run cannot reproduce CI's crate-hash-prefixed form; the regression fixture comes from the failing job's log, and the PR's own CI run is the end-to-end proof of the CI naming scheme.

**Pre-merge preconditions.** Branch based on current `main` (`debd7354`, never `gh pr merge --auto`), full range commitlint clean, all checks green on the exact head, `mergeStateStatus: CLEAN`.

## Lesson distilled

`progress/LEARNINGS.md` (CI/CD Patterns), two entries: filter generated symbols by declaration *shape*, never by one toolchain's literal spelling (and take the regression fixture from the environment that reproduces the failing names); and enumerate every input that can change an artifact inside its path filter — `src/wasm` is not `src/**`, and a green path-filtered PR is not coverage.
