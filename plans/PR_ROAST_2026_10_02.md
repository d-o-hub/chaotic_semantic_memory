### #807 — what the evidence gate and the body did not catch

The `feat:` title bypassed `scripts/check-perf-pr-evidence.py` entirely (`if not title.startswith("perf("): return 0`) while the body carried a ~6.4x headline. The number was checked by hand instead and does not hold:

- **A provably false documented invariant.** `complex_quadratic.rs:34-41` wraps each coordinate with `(v % 2.0) - 1.0` and the body calls the result `[-1.0, 1.0]`. Rust's `f64 % f64` is IEEE remainder with the sign of the dividend, so the reachable set is `(-3.0, 1.0)` (`v = -2.5` → `-1.5`). No simulation needed — the fmod sign rule is enough. It is also a per-coordinate wrap, not a fold of `|z|`, so the code is not the complex quadratic map whenever the branch fires.
- **No key, no hash.** `next_value(&mut self)` (`:48`) takes no input and produces no digest; `ChaoticLsh::new` hard-codes `Slhm2d` (`chaotic_lsh.rs:21-27`) and `grep -r ComplexQuadraticMap` finds zero callers repo-wide. The body's "fits securely into the existing LSH project semantics" has nothing behind it.
- **Bench blind by its arguments (the #800 class).** `c = -0.8 + 0.156i` is outside the main cardioid (`1 − sqrt(1−4c)` has modulus 1.066 > 1), so the orbit escapes and the `%` libcall sits on the hot path — while the body claims seeds "chosen near the Mandelbrot set boundary". The measured ratio therefore depends on a branch the prose never mentions. The *stated cause* is true (`Slhm2d::next` calls `libm::sin` twice per iteration, `hyperchaotic.rs:33-34`) and the harness is structurally comparable (same criterion group, same `b.iter`/`black_box` body, one iteration per arm) — that part is to the author's credit; the magnitude is not established.
- **The table self-contradicts.** Both rows read "Verified" for entropy while quality reads "Not measured", and the only distribution test is 20 000 samples into 10 buckets asserting `count > 0` (`:100-110`) — true of any stream producing 10 distinct values. The baseline row's "Verified" rests on the same class of test (`hyperchaotic.rs:94-104`).
- **Coverage regressed against its own prior submission.** #768 had `test_complex_quadratic_determinism`; #807 dropped it, while `hyperchaotic_chebyshev.rs:91-103` and `neural_circuit.rs:78` both keep one.
- **Citation:** Crossref `10.1016/j.chaos.2023.113647` resolves and matches the body's title/authors/journal (Ayubi, Setayeshi, Rahmani, *Chaos Solitons Fractals* 173, 2023). Full text is 403 at ScienceDirect, ResearchGate, ADS, Scilit and Bohrium, so the algorithm cannot be line-checked — which is exactly what the unretired `[FALLBACK]` marker says. The paper's contribution per the abstract is a *generalized* complex map used as a keyed hash with a key space, plus statistical/collision/key-space/speed analyses; the PR ships none of it.

### #806 — the duplicate is the real debt

Two live `ConceptBuilder` types exist: `crates/csm-memory/src/concept_builder.rs:28` (owner, clamped by `MAX_TTL_SECONDS_LIMIT`, exported as `csm_memory::ConceptBuilder`) and `crates/csm-memory/src/singularity_types.rs:178` (generic copy, **unclamped on main**, exported as `csm_memory::singularity::ConceptBuilder`). Production binds the *copy*: `src/framework.rs:17`, `src/framework_ttl.rs:7`, `src/framework_ops.rs:5`. `src/framework_ttl.rs:89` passes a caller-supplied `u64` into `.with_ttl()`, so `inject_concept_with_ttl(id, v, u64::MAX)` overflows on `main` today — a debug-build panic, a silent wrap in release (`no overflow-checks` anywhere in the workspace). `#[allow(dead_code)]` on a `pub` item suppresses nothing.

Verdicts:

- **Correctness: keeper.** The clamp fixes a live defect on the path production actually executes. Verified by mutation rather than by reading — reverting the `.min(MAX_TTL_SECONDS_LIMIT)` makes the new test fail, restoring it makes the test pass.
- **Undeclared behavior change:** `expires_at` moves from `with_ttl()`-time to `build()`-time. In-repo blast radius is nil (every call site chains `with_ttl` into `build()` immediately), but the type is public and `book/src/ttl.md:15-27` teaches it, so it is declared rather than smuggled.
- **Maintainer commit `9061a8f`:** the clamp shipped with no doc comment, so a public type silently gained a ceiling it did not state. Added the per-line contract (expiry resolves in `build()`; clamped to `MAX_TTL_SECONDS_LIMIT`; unset means never expires).
- **Test:** genuine, not tautological, but a near-verbatim duplicate of the owner's `concept_builder.rs:174-187`. Kept, because until the duplicate is collapsed the copy's clamp has no other coverage. The ±2 s window brackets two wall-clock reads — low-probability, structurally flaky under load, matching the convention the owner test already set.
- **Queued follow-up:** collapse the duplicate — reroute `use crate::singularity::ConceptBuilder` → `crate::concept_builder::ConceptBuilder` (`src/framework.rs:17`, `src/framework_ttl.rs:7`, `src/framework_ops.rs:5`, plus internal test imports), then delete `singularity_types.rs:177-232` and update `book/src/ttl.md`. The copy is the only one generic over `H`, and `grep 'ConceptBuilder<'` finds no non-default instantiation.

### #808 — remaining caveats recorded

The prior round's blockers are genuinely resolved: SAFETY/rationale comment count rose (22 → 26 occurrences of `SAFETY` in `hyperdim_simd.rs`), the `MaybeUninit` + `get_unchecked` fallback is gone in favour of the safe `xor_u64_scalar` oracle, and four parity tests pin the kernels against it on head/tail words and across the `BHVec`/`HVec` layouts. The dispatch sits next to the identical `hamming_distance_u64` packed-layout dispatcher, and `.codacy.yml` covers the extracted test module.

Two caveats the body does state and the record repeats here:

- **No in-repo hot path calls it.** `grep` for `BHVec10240::xor` / `Hypervector::bind` on the binary type finds only `crates/csm-core-lib/src/hyperdim_binary_tests.rs:14`. The win is on the public API surface and the benchmark.
- **The cited baseline is a near comparator, and the ratio is shape-dependent.** The body's `hvec_bind` comparator is a legitimate canonical id (`canonical.json`, 88 benches, no `bhvec_*` id exists), but it is the *other* layout's XOR. The 1.7–2.0x is a property of this compiler and this host; the body discloses loadavg ≈ 18 and alternates A/B to cancel drift, which is the right discipline.
