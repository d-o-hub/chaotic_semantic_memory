## `ci/goap-orchestrator-per-head-ci-truth` — `fix(ci): derive GOAP CI truth from the current main tip` (`46229f10`) — Self-Roast

Filed by reference to branch + commit rather than a PR number, since the number does not exist until this is pushed.

- **Why this exists and not just the prose rule:** #1009 changed a *sentence* while leaving the *mechanism* intact.
  `goap-orchestrator.sh:154` (`cmd_verify`) and `:244` (`cmd_status`) printed the last N `ci.yml` runs over every
  branch — `--limit 5 --json … headBranch`, no head SHA, no `--branch main --event push`. That output is precisely

  `scripts/`; no Rust, no workflow YAML, no `src/**`, so the mutation gate is not the enforcement point here and
  the fixture is.
- **Impact demonstrated, not asserted:** the function is called by both subcommands and prints a machine-greppable
  `ci-truth tip=<sha> state=…` line; the `red` path resolves the failing **job and step** through the jobs API, so
  the next session gets `failing_step=job=lint step=LOC gate` instead of inferring a cause from a job name — the
  mistake this file already records once today.
- **Bug found in the author's own first draft:** the row was parsed with `IFS=$'\t' read`, but `read` treats tab as
  IFS *whitespace* and collapses consecutive separators, so a running job's empty `conclusion` shifted `run_id` into
  `conclusion` and printed `state=pending run= status=in_progress`. Delimiter switched to `|`, with the reason in a
  code comment because the fix looks arbitrary without it.
- **Test is not vacuous — verified by mutation.** Reverting the delimiter to tab in a scratch copy makes the
  fixture fail loudly (`state=unverified`, the whole row landing in one field), so the pending case genuinely pins
  the parsing rather than passing either way. Cases: green, pending-with-empty-conclusion, red+step, stale-head,
  offline-no-gh.
- **Gate wiring checked, not assumed:** `scripts/validate.sh:462` already executes
  `test-goap-orchestrator-status.sh`, so these cases run in CI and in the pre-commit path without new registration.
  `shellcheck -x` clean on both files.
- **Title honesty:** `fix(ci)` — it is a tooling defect being fixed, not a `docs` note, and `ci` is a valid
  `commitlint.config.cjs` scope. No `perf(...)`, so the ADR-0095 evidence gate does not apply and no benchmark is
  claimed.
- **Honest limits:** the helper reports state; it does **not** fail the command, so a red `main` still exits 0.
  Making `verify` exit non-zero would change contract for existing callers and its fixture — deliberately out of
  scope here rather than silently bundled in.
- **Merge condition:** up to date with `27c88591` at authoring time; re-fetch `origin/main`, re-check
