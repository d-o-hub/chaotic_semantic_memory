## Merge discipline used

One PR at a time in the order `#1071 → #1072 → #1073`: each fetch of
`origin/main` forces a rebase check, each push is re-run through the commitlint
range, and each merge happens only when `gh pr checks` shows the required
contexts green **on that exact head** plus `mergeable`/`mergeStateStatus` is
`MERGEABLE`/`CLEAN` (ruleset: `lint`, `test`, `mutation-test`, `commitlint`,
`Build CLI (linux-x64)`, `Codacy Static Code Analysis`; CodeQL
`code_scanning`/`code_quality` can hold `BLOCKED` ~18 min after contexts go
green — wait it out, never treat it as a red). `--squash --delete-branch` only,
never `--auto`; squash subjects pre-measured (64/71/~72 chars < 100 budget).
