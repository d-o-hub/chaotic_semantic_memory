## What

Implemented Voronoi Diagram Encoded Hashing (VDeH) in `crates/csm-chaos/src/hashing/voronoi_lsh.rs` utilizing chaotic map trajectories to generate data-independent Voronoi centroids, projecting input embeddings to 10240-bit hypervectors.

## Research basis

"VDeH: Voronoi Diagram Encoded Hashing for Effective and Efficient Similarity Search, Applicable to Different Types of Databases" (Xu et al., published 2026-08-05). Source: DOI 10.1613/jair.1.21934

## Design

The implementation constructs hash functions by generating an ensemble of Voronoi boundaries (pairs of centroids) using the existing `Slhm2d` hyperchaotic map. It maps inputs into 10240 independent binary bits by assigning 1 if the input is closer to centroid A than centroid B, and 0 otherwise. This fits seamlessly into the `csm-chaos` hashing architecture beside `ChaoticLsh` and is heavily optimized using AVX2 and NEON intrinsics for vector L2 distance calculations.

## Tradeoffs

Benefits: Direct translation of VDeH logic into the hyperdimensional space, natively yielding mutually independent binary bits based on Voronoi partitions without requiring explicit data-driven training.
Limitations: Evaluated distance logic requires computing two full L2 distances per bit, resulting in higher latency (~12.58ms vs ~6.70ms) compared to pure scalar dot-product thresholds.
Numerical Risks: Fallback scalar distances could overflow if extremely large inputs are used; however, this is heavily mitigated by SIMD intrinsics accumulating into `f32` vectors safely.
Compatibility: Backward compatible, strictly gated behind a feature flag.

## Feature flag

Added to `crates/csm-chaos/Cargo.toml`:
```toml

```
Usage in `crates/csm-chaos/src/hashing/mod.rs`:
```rust

pub mod voronoi_lsh;
```
