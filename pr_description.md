## Design
Implemented a multiplier-free bitwise approach to avoid floating-point multiplication on the fast path, using f64 bit manipulations to provide non-linear structural variance. This maps nicely to this crate's requirements for hyper-dimensional chaotic iterations. It is gated behind the `experimental-svsc-4d` feature in `Cargo.toml`.

## Tradeoffs
Benefits: Extremely fast generation due to the multiplier-free bitwise formulation, enabling larger scale chaotic-based associative lookups.
Risks: Lower cryptographic robustness compared to more rigorous numeric models.
